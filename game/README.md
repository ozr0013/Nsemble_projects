# nsemble arena

Top-down arena survival game in Phaser 3 + TypeScript, built in parts by four humans and their agents
in an nsemble session. See [CONTRACTS.md](CONTRACTS.md) before touching anything.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests (event bus + game state)
npm run build      # typecheck + production build
```
